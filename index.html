03 / CLOSE THE GAP

Turn requirements into proof.

These suggested projects translate the researched job requirements into work you can show. They are preparation ideas, not employer requirements.

FDE

Build it. Explain it. Ship it.

  • Programming: practice Python or JavaScript/TypeScript, debugging, and data structures.
  • Data & applications: work with SQL, APIs, and a simple web interface.
  • Customer communication: clarify a problem, explain tradeoffs, and demonstrate your solution.
Portfolio project

Build an API-backed campus service dashboard. Interview a user, document the problem, and record a short demo explaining your decisions.

Requirement source: Palantir ↗
CYBERSECURITY

Investigate. Secure. Document.

  • Foundations: networking, Linux/Windows, access controls, and security logs.
  • Security practice: vulnerability review, monitoring, cloud security, and clear incident notes.
  • Automation: use scripts to inspect logs or check system settings.
Portfolio project

Use your own lab to analyze sample login logs, flag suspicious events, and write an incident report with a practical fix.

Requirement source: Anduril ↗
